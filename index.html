研究项目 · 01

RAG AGENT

面向知识库问答的智能助手，集成文档上传、分块管理、向量与 BM25 混合检索，支持多轮流式对话、工具调用轨迹与答案来源追溯。通过可视化工作台管理知识文档、检查切分结果并调试检索流程。

LangChainMilvusFastAPI / Vue 3
查看 RAG AGENT 项目说明

关注问题：如何让知识库问答能够找到相关文档，并给出可核对的答案来源。

实现思路：文档上传与分块 → 向量和 BM25 混合检索 → 生成回答与来源追溯，结合工作台检查中间结果。

交流重点：分块方式、混合检索和工具调用轨迹。尚未提供公开演示及独立项目仓库。
